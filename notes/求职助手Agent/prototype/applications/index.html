投递

每次投递一张卡，阶段跟着投递走。同一岗位投两次就有两张。

超过 14 天没有新进展的会标出来

改到「面试」

实现标注

  1. 数据：GET /api/applications（不传 job_id）。每条要多一个 stage_changed_at（最后一条阶段记录的发生日期），后端在查询里算，不存表。
  2. 一张卡 = 一次投递。岗位名、公司取 job_snapshot_json；user_job_id 为空时标「岗位已删除」。同一岗位有多条时标「第 N 次投递」。
  3. 没进展：阶段是已投递、笔试、面试，且距 stage_changed_at 超过 14 天。只是提示，不是阶段。
  4. 改阶段：卡片右下「改阶段」或列表里的下拉 → 弹层填发生日期 → PUT /api/applications/{id} 带修订号，409 时提示并重读。不做拖拽（理由见任务书）。
  5. 详情抽屉：复用岗位详情里现成的投递行，包括阶段记录、查看当时的简历、和现在对比、编辑、删除。
  6. 记录投递：先选岗位（只列有定制简历的），再进现成的记录投递弹窗。
  7. 窄屏：看板改成按阶段分组、上下排列；列表可横向滚动。
