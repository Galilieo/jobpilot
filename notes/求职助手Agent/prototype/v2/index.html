原型 v2 改了什么

2026-11-26，按现有界面实测和用户反馈整理。三个方向共用同一套交互，只是视觉不同。

交互问题（三个方向都修）

  1. 头像菜单展开时箭头翻转，按 Esc 或点外面关闭。
  2. 新对话的输入框放到欢迎语正下方，加粗边框和阴影；入口建议改成输入框下的一行小按钮，点了填进输入框。
  3. 一轮里的多个工具步骤合并成一行（「解析岗位、匹配、生成简历，3 步，用时 21 秒」），点开看每一步。
  4. 右侧面板只留一层标签（简历、匹配报告、岗位）；「显示依据」改成开关，字号、分页等收进「更多」。
  5. 改写后的条目在简历上标出事实编号，像脚注；改动过的条目带一条淡色底。
  6. 确认卡改前、改后并排，依据检查写明用了哪几条事实；确认后变成一行结果和「撤销」。
  7. 工作台顶部加输入框，发出后新建对话；三个统计并成一条，不再是三张一样的卡；空的看板列给出下一步。

三个方向

  • D 雾蓝 + 纸面（用户 2026-11-26 选定的方向）：以 A 为底，借 B 的宋体大标题（只用在欢迎语、工作台问候、简历姓名）、核对绿；确认卡、彩色实底的事实编号、改动条目的淡琥珀底、简历上方的绿色保证条沿用 A（用户 2026-11-26 反馈）；细节精修：事实编号悬停显示原文、圆角分层级、工具步骤展开为时间轴、数字等宽、元信息分开排而不用中点串。
  • A 雾蓝精修：保留现在的雾蓝主色，理顺层级。改动最小，风险最低。
  • B 档案纸面：整页像一份带批注的档案，简历面板更宽，标题用宋体，依据用「核对过」的绿色。
  • C 深色侧栏：深墨色侧栏，回复不用气泡、像文档；需要你处理的地方用琥珀色。

不在这一版

  • 窄屏布局沿用现在的做法（侧栏抽屉、面板全屏层）。
  • 「我的」与岗位库按选定的方向再统一，结构不变。
