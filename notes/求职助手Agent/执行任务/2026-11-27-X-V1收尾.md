### 1.2 使用统计脚本（只读）

写一个只读脚本，例如 `jobpilot/scripts/usage_stats.py`，从开发库统计**指定账号**的：

- 对话数，以及完成「贴 JD → 生成定制简历」的次数；
- 定制简历份数、改写条目数、依据检查通过 / 回退 / 待处理的条数；
- 用户手动修改过的条目数（版本差异）；
- 记录的投递数和各阶段分布；
- 模型调用次数和实际 token 用量。

要求：

- 只读，不改库，不调模型；
- 输出只有数字，不打印简历、JD 或对话原文；
- 先找现成的查询（`api/overview.py`、账号导出）复用，不另写一套口径；
- 用合成账号写一个测试。

用户的手填记录和脚本统计互相印证，README 里只用两边都能对上的数字。

### 1.3 干净副本启动验证

- 记下每一步实际执行的命令和用时；
- 文档和实际对不上的地方，直接改 README；
- 顺便确认 `.claude/launch.json` 里的 `api` 配置：它没带 `--reload`，代码更新后会继续跑旧代码，这正是 11-27 投递页白屏的原因。改成带 `--reload`，或者在 README 里写明「更新代码后要重启后端」，二选一，在回报里说明选了哪个。

### 1.5 README 骨架

先把不依赖评测数字的部分写好（第二段再填数字）：

7. **评测结果**：留占位，第二段填。
8. **局限**：先写已知的，例如只在本地使用、只支持 DeepSeek、评测是合成数据、已知限制 [10]，第二段再补。
9. **本地启动**：保留现在的内容，按 1.3 的验证结果修正。
