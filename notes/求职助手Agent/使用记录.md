目标：用真实 JD 通过对话走完至少 **10 次**「贴 JD → 生成定制简历」完整流程（完成标准见 [00 第 3.1 节](./00-总览与决策.md#31-v1-完成标准) 与 [04 第 4 节](./04-评测方案.md#4-使用记录与线上指标)）。

**与程序统计互相印证：**

```bash
uv run --project jobpilot python -m jobpilot.scripts.usage_stats --email <你的登录邮箱>
```

- **岗位**：只写方向和公司类型，例如「Agent 开发 · 大厂」，不写真实公司名也可以。
- **是否通过对话完成**：`是` 或 `否`（`否` 的话写卡在哪一步）。
- **改写条目数 / 接受数 / 手动改的条数**：可从简历面板数，或用统计脚本汇总核对。
- **需要手动修改的事实条数**：拆分或确认事实库时手动补充/修正的条数。
- **遇到的问题**：一句话，可顺带记下「离开产品手动修正的次数」（全程在产品内完成记 `0`，见 [06 第 7.1 节](./06-V1实施任务书.md#71-第-5-周本人使用与收尾)）。
